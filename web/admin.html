Anmelden

Zum Speichern braucht diese Seite einen GitHub-Schlüssel (Fine-grained Personal Access Token), der nur auf dieses Repository schreiben darf. Er bleibt nur in diesem Browser gespeichert.

  1. Neuen Token anlegen.
  2. Repository access: „Only select repositories“ → FF_visualizer.
  3. Permissions → Repository permissions → Contents: Read and write. Sonst nichts.
  4. Token erzeugen, kopieren und hier einfügen.
